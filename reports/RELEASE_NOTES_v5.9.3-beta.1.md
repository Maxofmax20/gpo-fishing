# GPO Autofish 5.9.3 beta 1

This optional candidate adds Telegram pity evidence and signed update/resume support.
Your existing installation, settings, calibrations and credentials are preserved.

- Confirmed fruit catches can read the separately labelled pity counter using bounded local OCR. No network vision or session-counter guesses authorize storage actions or alerts.
- Existing verified pity zero remains protected. Unreadable pity is reported honestly and does not pass the strict pity-zero-only alert filter.
- Complex post-workflow PNG screenshots are resized to fit the queue budget instead of silently discarded.
- Updates download while fishing continues, then wait between reels after fruit handling. Inputs are released and settings/lifetime records remain intact.
- A fresh, exact-version, one-use checkpoint enables automatic resume after the signed Windows installer restarts the app. Stop/Pause revoke resume; stopped sessions stay stopped.
- Update installation waits for pending notification attempts. Failed preparation or installer launch can restore the previous running session if a newer control action has not revoked it.
- Recorder/playback and crafting cannot start while update preparation is pending.

Includes the 5.9.2 fishing/playback fixes. Keep 5.9.0 running if it works best for your current session.
The first installation from an older version still needs a manual restart/resume; later updates can use the new handoff.

Automated Windows and frontend checks are required before publication. Actual Roblox gameplay, installer-to-installer handoff and extended AFK testing remain unverified; this is a prerelease.
