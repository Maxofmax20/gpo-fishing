# GPO Autofish v5.9.0

## Desktop and web repair
- Compact dark-red desktop and browser styling; specialist tools grouped under Advanced without deleting settings or modules.
- Settings and diagnostics are accessible without Roblox; optional page failures no longer take down navigation.
- Updater shows real download progress. Invalid web commands and failed saves no longer report success; desktop settings refresh after web changes.
- Browser credentials are removed from visible navigation URLs and kept in tab-scoped session storage. API requests use Bearer authentication; legacy image-stream authentication remains supported.
- All five web pages use compiled local CSS instead of a runtime style compiler. Controls have accessible names, keyboard focus and readable inactive states.
- Correct configured pity cap, honest initial counters and real connection badges. Failed crafting stops and telemetry refreshes no longer claim success.

## Fishing reliability
- Optional Continue after an unconfirmed ordinary fruit: observe again without a second drop, then resume while preserving the unconfirmed result. Off by default for existing installations; enable explicitly in Features. Protected fruits, explicit storage failures and manual cancellation retain their safeguards.
- High-contrast catch-text OCR fallback after an unknown normal read, using the same strict catch verification.
- Existing pity-zero-only post-action notifications remain intact.

## Performance
- Bounded visual telemetry queue; tracking updates skip hidden windows and never block fishing input.
- Bounded/deduplicated thumbnail loading; recent-catch status reads only a bounded log tail instead of the entire history.
- Added browser layout, reconnect, command-failure and WCAG accessibility checks at phone, tablet and desktop sizes.

## Verification limits
Automated checks gate publication. Real Roblox fruit handling, Windows hardware operations and a two-hour gameplay soak require the installed app and game; passing browser fixtures does not prove these physical checks. No gameplay FPS or native-memory improvement is claimed without measurement.
